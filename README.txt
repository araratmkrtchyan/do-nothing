Do Nothing v5.1 · Warm glass — offline copy

Open first: index.html (double-click). It is the whole prototype.
All screens: Screens.html lists every screen; each one also opens on its own.
Phones: the screen fills the full width; if Safari's bars take some height, the bottom scrolls into view. Saved to the Home Screen (from a web address), it opens as an app: the screen runs under a transparent status bar, with room for the home indicator.
Tablets and desktops: the whole screen shows, centred and scaled to the window.

Everything is inside this folder: the screens (*.dc.html), tokens.css, photos/ (if the style has photos) and offline/ (React 18.3.1 and the page runtime).
No server and no internet needed. Keep the folder together: moving one file out breaks its links.
Fonts: the system font (SF Pro on Apple devices), so no font files are needed.
