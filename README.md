# site: Do Nothing exports

Design versions exported as plain files that open in a browser with a double click, no server. One folder per version.

- Open `index.html` first: it lists every export.
- Each version folder has its own `index.html` (the prototype), `Screens.html` (every screen) and `README.txt`.
- Keep a version folder together: its pages, `tokens.css`, `photos/` and `offline/` link to each other by relative paths.
- A new export goes in a new folder named `vX.Y-style` and gets a line in `index.html`, then a commit.
